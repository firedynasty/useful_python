## What We Discussed

### 1. How the RAG System Works

The pipeline:
1. `create_rag_from_text.py` takes a .txt file
2. Parses into sections (chapters, parts, etc.)
3. Chunks each section (~1500 chars with 150 char overlap)
4. Creates embeddings using sentence-transformers (multi-qa-MiniLM-L6-cos-v1)
5. Stores in LanceDB (file-based vector database)

Folder structure created:
```
rag_yourname/
├── rag_config.toml
├── src/
│   ├── constants.py
│   └── retrieval.py
├── databases/lancedb/    ← vectors stored here
└── requirements.txt
```

### 2. Why Vector Search vs Raw Text

- Can't send entire book to Claude (token limits, expensive)
- Keyword search (grep) misses synonyms/meaning
- Vector search finds semantically similar content
- Example: "sidekick" query finds "squire" in text

### 3. How anthropic_chat_cli.py Uses RAG

```bash
python anthropic_chat_cli.py --rag rag_yourname --native "your question"
```

Flow:
1. Query embedded → vector
2. Search LanceDB for similar chunks
3. Rerank with cross-encoder
4. Format top chunks as [RAG Context]
5. Prepend to user's question
6. Send to Claude

### 4. Best Section Markers for parse_sections()

The script recognizes (in order):
- "Part X, Chapter Y Summary" (study guides)
- "Act I, Scene II" (plays)
- "WEEK 1: Title" (weekly guides)
- "Part 1" + "Chapter 1" (hierarchical)
- "Chapter X" or "CHAPTER X" (standalone)
- "PAGE X" (page markers)
- "1. Title" (numbered sections)
- Falls back to paragraph chunking

Best practice - use clear markers:
```
Chapter 1: The Beginning
...content...

Chapter 2: The Journey
...content...
```

### Plan: Font-Based Heading Detection

pdfminer can extract font info from LTChar objects:
- `char.fontname` → e.g., "Arial-Bold", "Helvetica"
- `char.size` → e.g., 18.0 (larger = heading)

Strategy:
1. Extract text WITH font metadata
2. Identify lines with large font size (>14pt) or bold fonts
3. Mark these as section headings
4. Output with `=== Section Name ===` markers

### Implementation Outline

```python
from pdfminer.layout import LTChar, LTTextLine, LTTextContainer

def extract_with_headings(pdf_path):
    """Extract PDF with heading detection based on font size."""
    sections = []
    current_section = {"title": "Introduction", "content": []}

    for page_layout in extract_pages(pdf_path):
        for element in page_layout:
            if isinstance(element, LTTextContainer):
                text = element.get_text().strip()
                if not text:
                    continue

                # Check font size of first character
                font_size = get_dominant_font_size(element)
                is_bold = is_bold_font(element)

                # Heuristic: Large font or bold = heading
                if font_size > 14 or is_bold:
                    # Save previous section
                    if current_section["content"]:
                        sections.append(current_section)
                    # Start new section
                    current_section = {"title": text, "content": []}
                else:
                    current_section["content"].append(text)

    # Don't forget last section
    if current_section["content"]:
        sections.append(current_section)

    return sections


def get_dominant_font_size(element):
    """Get the most common font size in a text element."""
    sizes = []
    for item in element:
        if hasattr(item, '__iter__'):
            for char in item:
                if isinstance(char, LTChar):
                    sizes.append(char.size)
    return max(sizes) if sizes else 12  # default


def is_bold_font(element):
    """Check if element uses bold font."""
    for item in element:
        if hasattr(item, '__iter__'):
            for char in item:
                if isinstance(char, LTChar):
                    fontname = char.fontname.lower()
                    if 'bold' in fontname or 'heavy' in fontname:
                        return True
    return False


def format_output(sections):
    """Format sections with markers for RAG."""
    output = []
    for section in sections:
        output.append(f"\n=== {section['title']} ===")
        output.append("\n".join(section['content']))
    return "\n".join(output)
```
