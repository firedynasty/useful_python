YouTube Transcript Extractor

Extract clean transcript text from YouTube page content

How to use:

  • On YouTube, click "Show transcript" below the video description
  • Select all the page content (Cmd+A) and copy (Cmd+C)
  • Paste the content into the Input area below
  • Click "Extract Transcript" - the clean transcript will appear in Output
  • Output is automatically copied to your clipboard
