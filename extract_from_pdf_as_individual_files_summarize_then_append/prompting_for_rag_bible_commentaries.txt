# Prompting Guide: Creating RAG from Bible Commentaries (Matthew Henry)

## Overview
This guide documents how to convert Matthew Henry Commentary HTML files into a
summarized text file suitable for RAG (Retrieval Augmented Generation) with
anthropic_chat_cli.py.

## File Naming Convention
MHC files follow this pattern: MHC{book_num}{chapter_padded}.HTM
- Book numbers: 01=Genesis, 02=Exodus, 03=Leviticus... 66=Revelation
- Chapter: 3 digits, zero-padded (001, 002, ... 050)

Example: MHC01001.HTM = Genesis Chapter 1


================================================================================
STEP 1: Convert HTML to Plain Text
================================================================================

First, convert each MHC HTML file to plain text (strips HTML, reduces file size).

PROMPT TO CLAUDE CODE:
---
I have Matthew Henry Commentary HTML files in ./matthew_henry folder.
File pattern: MHC{book_num}{chapter}.HTM (e.g., MHC01001.HTM = Genesis Ch 1)

Please convert all [BOOK_NAME] chapters to plain text files in ./[book]_txt/

Book numbers:
- Genesis = 01 (50 chapters)
- Exodus = 02 (40 chapters)
- Leviticus = 03 (27 chapters)
- Numbers = 04 (36 chapters)
- Deuteronomy = 05 (34 chapters)
- [etc.]
---

Claude Code will run something like:
```bash
mkdir -p ./exodus_txt
for i in $(seq -w 1 40); do
  input="./matthew_henry/MHC020${i}.HTM"
  output="./exodus_txt/Exodus_ch${i}.txt"
  if [ -f "$input" ]; then
    python /path/to/convert_html_to_txt.py "$input" "$output"
  fi
done
```


================================================================================
STEP 2: Summarize Each Chapter (Claude Code does this)
================================================================================

PROMPT TO CLAUDE CODE:
---
Please summarize Matthew Henry Commentary on [BOOK_NAME] for RAG.

Read each chapter from ./[book]_txt/ and create summaries (300-500 words each).

Output format (save to [book]_mhc_summarized.txt):

================================================================================
BOOK: [Book Name] - Matthew Henry Commentary (Summarized)
================================================================================

Chapter 1: [Title]
----------------------------------------
[Summary of main themes, interpretations, practical applications]

Chapter 2: [Title]
----------------------------------------
[Summary...]

[Continue for all chapters]

Focus on:
1. Main theological themes
2. Key verse-by-verse insights
3. Practical applications
4. Notable quotes or phrases
5. Cross-references to other scripture
---

Claude Code will:
1. Read each chapter file (batch by batch: 1-10, 11-20, etc.)
2. Create concise summaries
3. Write to a single output file with proper demarcations


================================================================================
STEP 3: Create RAG Database
================================================================================

PROMPT TO CLAUDE CODE:
---
Create RAG database from the summarized file:

python /Users/stanleytan/Documents/25-technical/46-python/extract_from_pdf/create_rag_from_text.py ./[book]_mhc_summarized.txt -o ./rag_[book]
---

This creates the RAG folder structure that works with anthropic_chat_cli.py.


================================================================================
STEP 4: Use the RAG
================================================================================

```bash
python /Users/stanleytan/Documents/25-technical/01-github/streamlit_apps/anthropic_chat_cli.py --rag ./rag_[book]
```

================================================================================
NOTES
================================================================================

1. DEMARCATION FORMAT
   The create_rag_from_text.py script automatically detects "Chapter X:" patterns.
   Each chapter becomes one retrievable chunk.

2. SUMMARY LENGTH
   ~300-500 words per chapter keeps file manageable while retaining key insights.
   Genesis 50 chapters = ~56KB summarized (down from 1.5MB raw)

3. BATCH PROCESSING
   For books with many chapters, Claude Code processes in batches (10 chapters
   at a time) to manage context.

4. OUTPUT STRUCTURE
   ./rag_[book]/
   ├── rag_config.toml
   ├── src/
   │   ├── __init__.py
   │   ├── constants.py
   │   └── retrieval.py
   ├── databases/
   │   └── lancedb/
   └── requirements.txt

5. COMBINING BOOKS
   You can concatenate multiple summarized files and create one RAG:
   cat genesis_mhc_summarized.txt exodus_mhc_summarized.txt > pentateuch.txt
   python create_rag_from_text.py pentateuch.txt -o ./rag_pentateuch
